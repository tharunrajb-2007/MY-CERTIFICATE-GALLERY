# 📜 My Certificate Gallery

## Project Overview

My Certificate Gallery is a simple HTML-based website developed to
organize and display all my certificates in one place. It serves as a
digital portfolio where visitors can view certificate details and open
certificates using the **View Certificate** button.

## Features

-   Home page
-   About Me section
-   Certificate Gallery
-   Serial Number column
-   Certificate Image preview
-   View Certificate button
-   Contact section

## Technologies Used

-   HTML5

## Project Structure

    my-certificate-gallery/
    ├── index.html
    ├── README.md
    ├── logo.png
    ├── *.jpeg

## How to Run

1.  Download or clone the repository.
2.  Open the project folder.
3.  Open `index.html` in a web browser.
4.  Click **View Certificate** to view any certificate.
